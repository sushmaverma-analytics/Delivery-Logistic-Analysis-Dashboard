# FedEX Delivery-Logistic-Analysis-Dashboard
 An end-to-end **Delivery Logistics Analytics** project built to analyze delivery performance, operational efficiency, cost, distance, vehicle utilization, delivery partners, and customer service outcomes.  The project uses **Microsoft Fabric, Notebook, Power BI to transform raw delivery data into an interactive business intelligence dashboard.
## 📌 Project Overview

Efficient logistics operations require organizations to understand:

- How much deliveries are costing
- Which regions have higher delivery costs
- Which delivery partners handle the most deliveries
- Which vehicle types are most frequently used
- How delivery modes affect delivery performance
- How many deliveries are completed on time
- Where delivery delays are occurring
- How distance impacts delivery cost
- Which package categories experience more delays
- How customer ratings relate to delivery performance

This project analyzes delivery logistics data and presents the results through an interactive **Power BI dashboard built in Microsoft Fabric**.

## 🎯 Business Objective

The primary objective of this project is to provide actionable insights into delivery operations and help logistics teams make data-driven decisions.

### Key objectives

1. Analyze overall delivery performance.
2. Monitor total delivery cost and distance.
3. Measure on-time and delayed deliveries.
4. Compare delivery partners.
5. Analyze vehicle-type utilization.
6. Compare delivery modes.
7. Analyze delivery performance by region.
8. Identify package types associated with delays.
9. Understand the relationship between distance and delivery cost.
10. Provide an interactive dashboard for business decision-making.
